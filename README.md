# Подарки 2027 — PWA

Приложение со списком людей, подарков, чекбоксами покупок, прогрессом и ручным учётом потраченной суммы.

## Что внутри

- `index.html` — интерфейс;
- `styles.css` — оформление;
- `app.js` — данные и логика;
- `manifest.webmanifest` — параметры PWA;
- `sw.js` — офлайн-кэш;
- `icons/` — иконки для iPhone;
- `.nojekyll` — служебный файл для GitHub Pages.

## Публикация на GitHub Pages

1. Создай на GitHub **публичный** репозиторий, например `podarki-2027`.
2. Распакуй архив `new-year-gifts-pwa.zip`.
3. В репозитории нажми **Add file → Upload files**.
4. Перетащи в окно **содержимое** папки `new-year-gifts`:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `manifest.webmanifest`
   - `sw.js`
   - папку `icons`
   - `.nojekyll`
5. Нажми **Commit changes**.
6. Открой **Settings → Pages**.
7. В разделе **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
8. Нажми **Save** и подожди 1–2 минуты.
9. Ссылка будет вида:

   `https://ТВОЙ_ЛОГИН.github.io/podarki-2027/`

## Установка на iPhone

1. Открой ссылку в **Safari**.
2. Нажми **Поделиться** — квадрат со стрелкой вверх.
3. Выбери **На экран «Домой»**.
4. Нажми **Добавить**.

После этого приложение запускается с иконки как обычное приложение.

## Данные

Приложение открывается с пустым списком. Данные хранятся только в `localStorage` браузера на телефоне и не отправляются на сервер.

Периодически делай **Экспорт** — это резервная копия в JSON. Через **Импорт** можно восстановить данные на другом устройстве.

Если очистить данные Safari, локальные данные пропадут. Резервная копия решит эту проблему.

## Как пользоваться

- На главном экране открой вкладку **Люди**.
- Нажми **+ Добавить**, чтобы добавить человека.
- В карточке человека добавь подарки через поле **Что купить?**.
- Чекбокс отмечает подарок как купленный.
- В поле **Потрачено на подарки** вводи сумму вручную.
- Крестик удаляет подарок или человека.
- Вкладка **Купить** показывает все некупленные подарки.
- Фильтры: «Все», «Докупить», «Собрано».
